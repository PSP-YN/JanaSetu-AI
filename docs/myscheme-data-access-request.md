# myScheme catalogue data access request — draft

**Recipient:** support-myscheme@digitalindia.gov.in
**Organization:** JanaSetu AI (independent public-benefits navigation prototype)
**Status:** Draft only; not sent; no permission or API access has been granted.

## Request

JanaSetu requests guidance on an authorized, machine-readable method for accessing the public scheme catalogue for non-authoritative discovery and linking users to the relevant official scheme pages.

Please advise whether NeGD / Digital India Corporation can provide or approve:

1. An official API, API Setu service, bulk export, or documented data feed for Central and State/UT scheme metadata.
2. The approved authentication method, access application process, technical documentation and test environment.
3. Permitted fields (scheme identifier, official title, jurisdiction, department, category, official detail URL, source language, last-updated timestamp, application URL, status and public eligibility/document metadata).
4. Whether the metadata may be cached, indexed and redisplayed in an independent non-government application; permitted refresh frequency, rate limits, attribution wording and redistribution conditions.
5. How amendments, withdrawn/merged schemes, expired application windows, duplicate records and language updates are represented.
6. Whether any additional State/UT department permissions are needed for the underlying source content.
7. The appropriate contact for a technical onboarding discussion and written authorization.

JanaSetu will not scrape myScheme pages, reverse-engineer private endpoints, bypass access controls or automate account-based access. Until written authorization and applicable terms are received, the product will link to myScheme and use only separately licensed/public datasets and manually verified official source records.

## Product safeguards

- Third-party machine-parsed records remain catalogue-only and are never eligibility evidence.
- Official scheme rules remain disabled until two independent qualified human reviewers approve the exact source and rule version.
- The application will display source publisher, source language, last-updated date and stale-data warnings.
- No Aadhaar, bank credentials, OTPs or sensitive identity documents are sent to myScheme through JanaSetu.
- JanaSetu is not a government service and does not make official eligibility decisions.
