# Presentation-generation prompt

Create a six-slide, 16:9 PowerPoint presentation for JanaSetu, an independent India-wide benefits navigation product. The audience is an AgentX-style hackathon selection panel evaluating problem fit, agent design, working feasibility, innovation and presentation quality.

Use exactly six slides:
1. Product vision and one-line promise.
2. The citizen's fragmented benefit-access workflow and specific pain points.
3. JanaSetu workflow and signature Benefit Readiness Graph.
4. Multi-agent architecture, tools, data and mandatory human approval.
5. Competitor/ecosystem comparison: myScheme, UMANG, DigiLocker and CSC; clearly acknowledge that discovery and multilingual access already exist and position JanaSetu as an evidence-to-action preparation layer.
6. Prototype scope, three-minute demonstration, measurable pilot metrics, trust boundary and scale roadmap.

Design constraints:
- Editorial, premium, restrained enterprise/public-service design.
- Palette only: warm ivory (#F5F2E9), deep forest green (#1F4633), charcoal (#242A24), muted sage (#AAB8A0), terracotta (#B86643), warm sand (#E8DDC6), white (#FFFDF8).
- Absolutely no purple, violet, indigo, blue, cyan, or gradients.
- Do not use generic AI stock imagery, glowing brains, 3D globes, robot illustrations, or decorative gradients.
- Use clean diagrams, thin rules, large editorial headings and carefully aligned cards.
- Maintain consistent 0.45-inch margins, baseline grid, typography and footer.
- Keep each slide readable from a projector; avoid paragraphs and tiny footnotes.
- Use authentic diagrams and simple vector pictograms rather than decorative image filler.
- Include source URLs or compact source labels on evidence-bearing slides.
- Exactly six slides; do not add a title-only or appendix slide.

Narrative:
JanaSetu does not claim to invent scheme discovery or multilingual scheme chat. Official platforms such as myScheme and UMANG already provide broad discovery and service access. JanaSetu's differentiation is a citizen-controlled execution-preparation layer: a reusable profile, rule-to-evidence traceability, explicit unknown states, document readiness, draft preparation and follow-up memory.

Prototype honesty:
- All 36 States and Union Territories can be selected in the citizen profile.
- The current working catalogue is a limited set of four curated Central Government schemes, not complete State/UT coverage.
- Current agent tools are deterministic server-side functions coordinated by a planner; do not claim external LLM inference.
- Document handling stores file metadata only; do not claim OCR or document-content parsing.
- Drafts and reminders are browser-local prototype records; no government application is submitted.
- Eligibility is preliminary; final decisions belong to the responsible department.

Use the following source links for research and compact footnotes:
- https://www.myscheme.gov.in/faqs
- https://web.umang.gov.in/
- https://www.pib.gov.in/PressReleasePage.aspx?PRID=2298116&lang=1&reg=1
- https://pmkisan.gov.in/
- https://pmay-urban.gov.in/uploads/guidelines/Operational-Guidelines-of-PMAY-U-2.pdf

- https://www.education.gov.in/sites/upload_files/mhrd/files/upload_document/FAQs_PM_USP_CSSS_scheme_AY_2025_26.pdf

Do not invent impact numbers, market sizes, scheme counts or performance metrics. Distinguish current prototype features from the target production roadmap.
